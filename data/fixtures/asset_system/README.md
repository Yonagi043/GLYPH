# Asset-system fixture

`open_fixture.pgm` is a synthetic grayscale shape generated for GLYPH tests. It
does not reproduce a logo, typeface, award work, or other third-party asset.

The GLYPH contributors dedicate this fixture to the public domain under
`CC0-1.0`. It may be redistributed and transformed. Its curation records use
`review.method=fixture_protocol`; that marker is test metadata, not a claim of
human review. Every stimulus produced from this file must remain
`release_status=fixture_only`.
