# 10 项指标：数学公式与 CV 实现

## 0. 统一符号与预处理

对一张样本图像定义：

- `I(x,y)`：灰度图，归一到 `[0,1]`，黑色为低值；
- `A(x,y)`：有效前景/墨迹 alpha 或二值掩膜；
- `B=1[A>0]`：前景二值图；
- `S`：对 `B` 做细化得到的单像素骨架；
- `D(x,y)`：到背景的欧氏距离变换；
- `w(s)=2D(s)`：骨架点处的局部笔画宽度；
- `Ω`：归一化画布，坐标范围 `[0,1]×[0,1]`；
- `m=ΣA`：前景质量（墨量/面积代理）；
- `μ_A=ΣA(x,y)(x,y)/m`：视觉重心；
- `d_c(a,b)=|atan2(sin(a-b),cos(a-b))|`：圆周方向距离。

所有分数先保留原始特征，再用同类别训练集的中位数和 MAD 或 z-score 归一化。以下 `exp` 分数只是便于展示的单项分数，不能替代人评校准。

## 1. D1 平衡

### 数学定义

重心偏移：

`δx=μx-0.5, δy=μy-0.5`

中心平衡代理分数：

`B_center = exp[-(δx²/τx² + δy²/τy²)]`

若要测不对称造成的视觉力矩，令：

`M = Σ A(x,y) ((x-0.5),(y-0.5)) / m`

同时输出 `δx, δy, ||M||`，不只输出 `B_center`。对有意偏心的 Logo，`0.5` 改为同类样本或盲评数据学习出的最优中心 `c*`。

### CV 算法

1. alpha 合成/背景估计；
2. 得到 `A`，计算重心和二阶矩；
3. 计算四象限质量差、左右/上下镜像差；
4. 对多元素 Logo 计算每个连通域的面积、对比度和位置，形成视觉重量 `q_i=area_i×contrast_i`；
5. 输出原始特征与按 cohort 校准的分数。

### 评价规则

高分不是“必须正中心”，而是相对于任务和同类原型具有稳定的视觉组织；应人工检查中心偏移是否是有意的动势。

## 2. D2 对称

### 数学定义

水平镜像与垂直镜像差异：

`S_h = 1 - ||B-flip_h(B)||_1 / (||B||_1+ε)`

`S_v = 1 - ||B-flip_v(B)||_1 / (||B||_1+ε)`

`S_mean=(S_h+S_v)/2`

可选旋转对称：

`S_r(θ)=1-||B-R_θ(B)||_1/(||B||_1+ε)`，在 `θ∈{90°,180°}` 上取值。

### CV 算法

将前景按相同画布对齐，计算镜像 IoU、Chamfer distance 和轮廓 Hausdorff distance。对于文字，先报告整体对称，再报告部件级对称，避免因字符语义结构误判。

### 评价规则

对称是可解释特征；审美评分模型应允许非线性，例如 `score = β0+β1S+β2S²`，以容纳“适度对称最好”的情况。

## 3. D3 比例与尺度

### 数学定义

整体宽高比：`r_wh=W/H`。

以 cohort 参考分布 `(μ_r,σ_r)` 定义：

`P_wh = exp[-(log r_wh-μ_r)²/(2σ_r²)]`

字形/Logo 内部比例向量可取：

`p=[W/H, area_box/area_canvas, median(w)/min(W,H), void_area/ink_area]`

用马氏距离衡量与同类参考分布的接近程度：

`P = exp[-(p-μ_p)^T Σ_p^{-1}(p-μ_p)/2]`

### CV 算法

检测前景 bounding box、凸包、最小外接旋转矩形、局部空腔；提取笔画宽度中位数和四分位距。不要默认黄金比例；若要测试黄金比例，把 `φ` 作为待检验的候选变量而不是理论真值。

## 4. D4 统一/一致性

### 数学定义

将每个部件或笔画分成 `n` 个单元，提取风格向量：

`f_i=[w_i, curvature_i, corner_i, endpoint_i, contrast_i, color_i,...]`

内部一致性：

`U_raw = tr(Cov(f_1,...,f_n))`

`U = exp[-U_raw/τ_U²]`

更稳健的版本使用平均 pairwise distance：

`U_pair = 1 - mean_{i<j} d(f_i,f_j)/d_ref`

### CV 算法

连通域/骨架分段 → 提取局部宽度、曲率、角点半径、端点形状和明度 → 计算协方差、pairwise distance、聚类轮廓系数。Logo 允许主次层级，因此可对不同语义层分组计算。

### 评价规则

统一不等于同质化。报告“总体一致性”和“层级间差异”，防止把必要的主次关系误判为不统一。

## 5. D5 节奏/序列

### 数学定义

沿主轴或书写/阅读顺序得到序列 `z_t`（可为部件间距、笔画宽度、方向或面积）。其周期性特征：

`R_period = max_{f∈F} P_z(f) / (Σ_f P_z(f)+ε)`

其中 `P_z` 是序列功率谱，`F` 为排除直流后的合理频段。

变化控制：

`R_var = exp[-|CV(Δz)-c*|/τ_R]`

最终保留 `R_period`、`CV(Δz)`、自相关峰值和序列长度，不直接把“规则越强越美”写死。

### CV 算法

对 Logo 用 PCA 主轴排序部件；对字体/书法用字符阅读顺序或已知 stroke order；提取 spacing、width、orientation 序列；用 FFT/自相关/小波得到多尺度节奏。

## 6. C1 笔法与线质

### 数学定义

骨架曲率 `κ(s)`、局部宽度 `w(s)=2D(s)` 和边缘粗糙度 `e(s)`：

`L_raw=[median(w), CV(w), median(|dκ/ds|), edge_roughness, endpoint_count, break_rate]`

可展示的平滑/控制代理：

`L_control = exp[-CV(w)/τ_w] × exp[-Var_smooth(κ)/τ_κ] × (1-break_rate)`

它不是“书法美”的充分条件；有表现力的作品可能具有更高的受控变化。

### CV 算法

二值化/去噪 → Zhang-Suen 或等效细化 → 骨架图分支检测 → 距离变换测宽 → spline 拟合曲率 → 端点/起收笔局部轮廓 → 统计边缘粗糙度。已有工作使用 skeleton、stroke thickness、SWT 和 contour 特征，可复现这一路线。

## 7. C2 结体/字内结构

### 数学定义

将归一化字形放入米字格或八区网格，得到占比向量 `q∈R^8`。结构偏差：

`C_grid = exp[-(q-μ_script)^T Σ_script^{-1}(q-μ_script)/2]`

骨架图 `G` 的拓扑特征包括端点数、分叉点数、主轴方向和分支长度；对齐后可用 SSIM：

`C_skel = SSIM(S_1,S_2)`

项目内比较同一字符/同一构件时，再使用：

`sim(x,y)=1/(1+sqrt(Σ_k(x_k-y_k)^2))`

### CV 算法

字符分割 → 形状归一但保留长宽比 → 米字格八区投影 → 骨架和内外轮廓 → 与同书体 cohort 或参考样本比较。Zhang 等开放全文明确采用 skeleton、outer/inner contour、rice-grid area、SWT、连通域和 SSIM/欧氏距离。

## 8. C3 布白/章法

### 数学定义

设前景掩膜为 `B`，整体墨量密度：

`ρ = |B|/|Ω|`

边界留白向量 `m=[m_top,m_bottom,m_left,m_right]`；内部空腔面积比例 `v=area(holes)/area(B)`；多字布局的最近邻间距向量为 `g`。

相对参考分布的布局分数：

`K = exp[-([ρ,m,v,g]-μ_layout)^T Σ_layout^{-1}([ρ,m,v,g]-μ_layout)/2]`

### CV 算法

连通域/字符行检测 → 计算外边界、孔洞、行列投影和最近邻距离 → 输出局部（字内）与整体（字间/行间）两层特征。原图版用于章法，形状归一版只用于字内布白。

## 9. C4 墨法/墨色层次

### 数学定义

在有效墨迹区域取灰度直方图 `p(g)`：

`D_ink = 1-mean(I|A)`（平均浓度）

`H_ink = -Σ_g p(g)log(p(g)+ε)`（灰度熵）

`C_local = mean_{patch} std(I_patch)`（局部对比）

`E_spread = mean(edge_spread)`（边缘扩散/渗化代理）

组合特征向量：

`Ink_raw=[D_ink,H_ink,C_local,E_spread,percentile_10,percentile_90]`

若需要单项分数，按作品/纸张 cohort 学习 `Ink_score=β^T z(Ink_raw)`，不要把“更黑”直接设为更好。

### CV 算法

颜色校准/背景建模 → 纸张与墨迹分离 → 保留灰度而非直接二值化 → 多尺度局部统计、边缘扩散、纹理 GLCM/LBP（可选） → 对扫描质量做协变量校正。

## 10. C5 气韵/行气/力势代理

### 数学定义

将骨架切成有序笔画/段 `j=1...J`，每段方向为 `θ_j(s)`，方向一致性：

`D_dir = |(1/N)Σ_s exp(iθ(s))|`

相邻段连续性：

`Q_cont = exp[-mean_j d_c(θ_j,end, θ_{j+1},start)^2/τ_θ²]`

粗细行气：对 `w_j=median(w|stroke_j)` 使用第 5 项节奏公式得到 `R_width`；连带/粘连可用归一化连通域指标 `K_conn` 表示。

可解释的代理组合：

`Qi_proxy = λ1 D_dir + λ2 Q_cont + λ3 R_width + λ4 K_conn`

其中 `λ` 必须通过人评或专家标注校准。该式测的是“可见力势/行气代理”，不是形而上的 qi 本体。

### CV 算法

骨架图和 stroke order → 切分段 → 方向场/曲率/宽度序列 → 连续性与频谱 → 多尺度可视化（方向场、宽度山形图、连带图）。Zhang 等人的开放全文已用笔画厚度序列和连带特征辅助风格比较；Shi 的理论说明为什么这些低层特征可作为 force-form 的代理。

## 11. 统一评分与统计模型

不要先手工指定 10 个固定权重。推荐：

`y_{pi}=α + Σ_d β_d x_{id} + u_p + v_i + γ^T controls + ε_{pi}`

其中 `y_{pi}` 是参与者 `p` 对样本 `i` 的评分，`u_p` 为参与者随机效应，`v_i` 为样本随机效应，`controls` 可含展示尺寸、图像质量、熟悉度、母语组等协变量。若是排序任务，用 Bradley–Terry/Thurstone；若是 1–7 Likert，用 ordinal mixed model。

验证指标：ICC/Cronbach α（评分可靠性）、Spearman/Kendall（排序一致性）、留出集 RMSE/MAE、跨文化组的 calibration error。模型解释使用 SHAP 或系数置信区间，并报告“去掉社会标签后”的性能。
