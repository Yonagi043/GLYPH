# 数据标准化与实验流程

## 1. 三通道原则

同一原始样本 `raw_i` 生成三条分析通道，禁止用一条被过度处理的图承担所有指标：

| 通道 | 保留 | 主要用途 |
|---|---|---|
| A 版面保持版 | 原始画布、真实边距、相对位置、原始尺度 | D1 平衡、D3 整体比例、C3 章法 |
| B 形状归一版 | 前景 bbox 归一到固定画布，保留长宽比；记录变换参数 | D2 对称、D4 统一、C1 笔法、C2 结体 |
| C 墨色保留版 | 原始灰度/颜色、背景校正结果、alpha | C4 墨法；颜色只作单独协变量 |

对 Logo 另存“组件保持版”，不要把文字、图形和奖章符号误合并成一个笔画系统。

## 2. 建议目录结构

```text
dataset/
  raw/                         # 原图，只读
  metadata/                    # 来源、年份、奖项、作者、授权、SHA-256
  canonical/layout/            # A 通道
  canonical/shape/             # B 通道
  canonical/ink/               # C 通道
  masks/                       # 前景、孔洞、纸张掩膜
  features/                    # 逐样本 CSV/Parquet
  ratings/                     # 盲评原始数据
  splits/                      # train/validation/test，按作品/作者分组
```

## 3. 统一预处理

1. 保存原文件、下载 URL、访问日期和 SHA-256；
2. 统一色彩空间到 sRGB，记录原始分辨率和 DPI；
3. 估计背景并生成 alpha；纸张纹理不得直接计入笔画面积；
4. 生成灰度版和二值版，但保留阈值、滤波核和软件版本；
5. 连通域、孔洞、骨架提取失败时写入 QC 状态，不静默丢样本；
6. 对每种文字/书体/Logo 类型分别计算参考分布，避免跨类别尺度混淆。

## 4. 人评设计建议

### 盲评条件

- 隐藏奖项、年份、作者、品牌、媒体截图、文件名中的语义线索；
- 固定显示尺寸、背景、观看时长和随机顺序；
- 另设“带社会标签”条件，用于研究附加值，但不能混入纯视觉真值。

### 任务

每个样本至少收集：总体审美、平衡、清晰/流畅、结构、节奏/动态、墨色（适用时）等评分；对不适用项提供明确选项。母语、识字量、设计训练、书法训练、对奖项熟悉度作为协变量，不把母语直接当作样本标签。

### 样本划分

按作品/设计师/同一奖项 package 分组切分，不能把同一 Logo 的不同年份图放进训练和测试两侧，否则会产生泄漏。

## 5. 质量控制与可复现

- 每次处理输出 `pipeline_version`、参数 JSON 和软件环境；
- 10% 样本人工检查：前景掩膜、bbox、骨架、孔洞、灰度背景；
- 记录失败原因：低分辨率、遮挡、复合图层、文字不可分割、背景复杂；
- 模型报告原始特征、校准后的特征和最终权重三份结果；
- 任何“剔除命题无关特征”的操作都要先保存原图和可逆变换参数。

## 6. 与社会学流量监控任务的接口

视觉模型只读取 `x_visual`。社会变量另建 `x_social`：奖项级别、获奖年份、曝光量、转发量、媒体语调、设计师声誉等。比较：

`M_visual: y ~ x_visual`

`M_full: y ~ x_visual + x_social`

若 `M_full` 的提升主要来自 `x_social`，即可量化社会附加值；若某些 `x_social` 改变了人们对同一图的评分，则可进一步检验刻板印象/标签效应。
