# 分项分数与总分说明

## 1. 当前总分的性质

程序的 `total_score` 是 `rule_proxy_v1`：依据 10 项理论指标构造的透明规则基线。它的用途是验证 CV 特征提取、建立可解释基线，并为 AutoResearch 提供可搜索的起点；它不是已经通过人类盲评或 SFT 模型校准的普适“高级感真值”。

## 2. 从原始特征到 0—100 分

多项指标使用指数距离函数：

\[
E(d;\tau)=100\exp[-(d/\tau)^2]
\]

当一个特征与当前规则设定的参考点完全一致时为 100；偏离越远分数越低。这里的参考点和尺度是 MVP 默认值，后续应按字体/Logo 类别，通过 AutoResearch 或人评数据校准。

### D1 平衡

计算重心与画布中心的欧氏距离 `d_center`，以及四象限前景密度最大差 `d_quad`：

\[
S_{balance}=0.7E(d_{center};0.20)+0.3E(d_{quad};0.25)
\]

### D2 对称

将主体与水平镜像、垂直镜像和 180° 旋转结果比较，得到 `S_h`、`S_v`、`S_180`：

\[
S_{sym}=100(0.4S_h+0.4S_v+0.2S_{180})
\]

这些量是形状重合度代理。当前基线偏好对称；正式审美模型可以学习倒 U 型，而非假定越对称越好。

### D3 比例

当前基线使用三个宽松参考点：宽高比接近 `1`、主体边界框占画布约 `0.35`、内部孔洞/前景约 `0.15`：

\[
S_{prop}=0.4S_{aspect}+0.35S_{occupancy}+0.25S_{void}
\]

这些不是普适美学常数，应按汉字、拉丁字、文字 Logo、图形 Logo 等类别分别校准。

### D4 统一

由局部笔画宽度变异 `CV_w` 与方向分散度 `D_o` 构造差异：

\[
d_u=0.7CV_w+0.3D_o,\quad S_{unity}=E(d_u;0.45)
\]

当前版本衡量局部线形的一致程度；复杂 Logo 的语义组件分层尚未加入。

### D5 节奏

将连通组件沿第一主轴排序，以组件间距形成序列，计算：

- 非零滞后自相关 `A`；
- 功率谱主峰占比 `P`；
- 间距变化系数 `CV_g`。

\[
S_{rhythm}=100[0.45(A+1)/2+0.35\min(1,2P)+0.20E(|CV_g-0.25|;0.25)/100]
\]

组件不足以形成序列时，当前程序返回中性基线 50；这表示“信息不足”，不是确认节奏中等。后续版本应改为基于笔画顺序或轮廓序列分析。

### C1 笔法与线质

通过 Zhang–Suen 骨架和距离变换获得局部宽度，计算宽度变化、骨架断裂：

\[
S_{brush}=0.55E(CV_w;0.65)+0.30E(R;0.65)+0.15(1-B)100
\]

其中 `R` 是当前边缘/宽度粗糙代理，`B` 是断裂率代理。

### C2 结体

将归一化主体划入八个方向区域，计算区域占比离散程度；再加入骨架分叉/端点比例作为拓扑稳定代理。由于没有“同字、同书体”的参考模板，本项目前只是结构分布基线，正式版本应使用同类别均值与协方差或参考字模板。

### C3 布白/章法

计算四边留白不均衡、整体墨量密度和横纵投影变化：

\[
S_{space}=0.55E(d_{margin};0.18)+0.25E(\rho-0.25;0.25)+0.20E(V;0.35)
\]

其中 `d_margin` 为四边留白的标准差，`ρ` 为前景密度，`V` 为投影变化代理。

### C4 墨法

有有效灰度层次时，使用平均墨浓度、灰度熵、局部对比和边缘扩散：

\[
S_{ink}=0.25S_{density}+0.35S_{entropy}+0.25S_{contrast}+0.15S_{spread}
\]

近似纯黑白的数字字体或 Logo 被标记为 `N/A`，不进入总分分母。

### C5 气韵/行气代理

这不是对“气韵本体”的测量，而是可见形态代理：

\[
S_{qi}=100(0.30D+0.30C+0.20R_w+0.20K)
\]

其中 `D` 为方向一致性，`C` 为局部方向连续性，`R_w` 为粗细变化节奏，`K` 为骨架连通性。

## 3. 总分公式

设第 `j` 项分数为 `s_j`，权重为 `w_j`，适用标记为 `a_j`：

\[
S_{total}=\frac{\sum_{j=1}^{10}a_jw_js_j}{\sum_{j=1}^{10}a_jw_j}
\]

当前默认：

```text
w1 = w2 = ... = w10 = 0.1
```

如果墨法不适用，则它的 `a_j=0`，剩余九项重新归一化，不会因为缺少墨色被扣 0 分。

权重可以通过 `--weights weights.json` 替换。权重文件只决定分项如何汇总，不能自动证明某一组权重正确。

## 4. 如何与 SFT 和 AutoResearch 对接

当前输出应作为融合模型输入：

```text
x = [SFT综合分, 10项CV分, CV原始特征, QC状态]
```

AutoResearch可搜索：

- 各维度权重；
- 指数距离中的参考点与尺度；
- 线性、二次项、GAM或残差校正融合；
- 不同字体/Logo类别的独立参数。

推荐最终形式是：

\[
S_{final}=Calibrate(S_{SFT})+f(x_{CV})
\]

其中 `f` 学习 SFT 相对独立盲评的残差。只有冻结测试集上优于 SFT 单独基线，才能说 CV 融合带来了有效改进。
