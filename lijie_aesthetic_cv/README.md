## 生产状态

本目录的理论、公式、字段字典和检索日志继续作为理论来源保存。`cv_program/` 现为历史原型，不再是独立生产管线；其中未经真人校准的规则分和 `total_score` 不进入 canonical 数据或联合分析。可执行迁移入口已并入根锁定环境的 `glyph-vision-legacy`，并只输出版本化 registry 定义的原始/诊断测量。

## 重要结论

1. “审美指标”不是越大越好。对称、居中、均匀等通常是特征，不是普适最优值；最终方向和区间应由同类样本的人评数据校准。
2. 书法中的“气韵、气势”不能被宣称为一个被 CV 直接测量的实体。本项目把它拆成方向连续性、粗细变化、连带关系和多尺度节奏等可检验代理变量。
3. 同一样本必须保留三种版本：版面保持版、形状归一版、墨色保留版。把所有图先强行居中、等比例裁切、二值化，会把要研究的版式、结体、笔法和墨法提前抹掉。
4. 获奖与否、奖项等级、传播量不能作为“审美真值”。它们属于社会学变量，应与视觉特征分开建模。

## 建议的最小可行实验

对每个字体/Logo 样本：

1. 生成三通道标准图并保存原图哈希；
2. 提取 10 个指标的原始特征，不先压成一个总分；
3. 由不同母语、不同设计经验的受试者进行盲评；
4. 用混合效应模型或分层 Bradley–Terry/ordinal model 估计指标权重；
5. 用留出样本检验指标对“审美评分”的解释力，而不是检验它能否预测获奖。
