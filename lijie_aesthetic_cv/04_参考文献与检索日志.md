# 参考文献与检索日志

## A. 检索声明

- 时区：Asia/Shanghai；最后一次整理时间：2026-09-02。
- 文献元数据主要通过 Crossref、OpenAlex、Semantic Scholar DOI API 核验；正文/摘要优先使用出版社页面或开放全文。
- 访问到的页面、API 返回和失败状态均记录；不能访问全文的来源只用于书目信息或摘要，不把未核验内容写成原文结论。
- 书法古籍的原始版本/中文全文在本环境部分站点超时，因此古典术语采用已核验的学术论文、书目和可追溯译注作为入口，后续若要做古籍训诂应另行人工核版。

## E. 证据等级

- A：出版社正文/开放全文中直接核验到的方法或摘要。
- B：Crossref/OpenAlex/Semantic Scholar 的 DOI 元数据与摘要，适合书目和研究结论概览。
- C：经典书籍/古籍的书目入口，尚需人工核对具体页码或中文版本。
- D：搜索结果、推荐结果或未能打开的页面，只作线索，不作为结论证据。
