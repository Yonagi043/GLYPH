# 研究结论：5 个设计指标 + 5 个书法指标

## 1. 筛选口径

这里的“代表性”采用三个条件交集，而不是凭个人偏好指定：

1. 在经典设计/艺术理论或书法理论中反复出现；
2. 能写成观察者可以执行的评价规则；
3. 能由图像或矢量轮廓提取可复现特征。

设计侧的经验研究支持平衡、统一、序列/节奏、比例、简洁、密度、秩序等维度；书法侧的理论与计算研究反复涉及笔画/线质、结体、空间布置、墨色变化、力势/行气。最终选出的 5+5 如下。

## 2. 设计理论侧：5 项

### D1 平衡 Balance

**观察规则**：视觉重量在画面中形成稳定但不必绝对对称的分布；主体、留白和局部高密度区域之间没有明显“倾倒”。评价时记录水平/垂直重心偏移、视觉力矩和局部重量差，不把精确居中当作唯一好答案。

**理论/证据**：Arnheim 的视觉知觉理论；Locher、Gray 与 Nodine 对构图平衡中心的实验研究；Ngo、Teo 与 Byrne 的界面审美模型；Altaboli 与 Lin 对 balance 的计算实验。

### D2 对称/镜像关系 Symmetry

**观察规则**：在垂直、水平、旋转或局部镜像关系上存在可辨识的对应；偏离对称是否有意、是否产生张力，另行记录。对称度是描述变量，不是强制规范。

**理论/证据**：Gestalt 传统；Bauerly 与 Liu 对 symmetry 与构成元素数量的实验；Reber、Schwarz 与 Winkielman 对对称、典型性和加工流畅性的综述。

### D3 比例与尺度 Proportion / Scale

**观察规则**：整体宽高、主体与留白、部件之间的尺寸关系协调；笔画厚度、字腔、图形外框和负形之间处在可读且有风格的区间。比例应相对于同类字种/Logo 类型校准，不默认黄金比例。

**理论/证据**：Arnheim 的结构知觉；Wucius Wong 的形式与设计教学传统；Deng 与 Wang 的比例、密度、秩序、节奏、平衡量化模型；排印与字形设计实践。

### D4 统一/一致性 Unity / Consistency

**观察规则**：多个部件共享一套可识别的形态语法，例如相近的粗细系统、转角逻辑、曲率风格、端点处理、色彩或明度规则；允许有层级差异，但不能像来自互不相容的系统。

**理论/证据**：Gestalt 的整体性与良好形态；Ngo、Teo 与 Byrne 的 unity；Altaboli 与 Lin 的 balance–unity–sequence 实验；现代 UI/图形审美量化研究。

### D5 节奏/序列 Rhythm / Sequence

**观察规则**：重复元素的间距、方向、粗细或形状变化形成可追踪的视觉节拍；高质量节奏通常是“重复 + 有控制的变化”，不是机械等距。评价需同时记录周期性和变化幅度。

**理论/证据**：Gestalt 的接近/相似/连续；Ngo、Teo 与 Byrne 的 sequence；Altaboli 与 Lin 的 sequence 实验；Deng 与 Wang 的 rhythm 指标；书法理论中行气与连续性对设计侧的启发。

## 3. 书法理论侧：5 项

### C1 笔法与线质 Brushwork / Line Quality

**观察规则**：线条的起收、转折、粗细、边缘和曲率变化是否连贯、有控制力；是否出现无意义毛刺、断裂、粘连或不一致的端点。数字图像只能测到笔迹留下的形态代理，不能还原全部书写动作。

**理论/证据**：Chiang Yee《Chinese Calligraphy》；Shi 对“形—势（xing–shi）”的讨论；Wang、Liao 与 Maekawa 的圆润度、平滑度、宽度、墨量和稳定性量化；Zhang 与 Nagy 的书法风格视觉属性；Zhang 等人的骨架/厚度特征。

### C2 结体/字内结构 Character Structure

**观察规则**：部件比例、重心、穿插、向背、疏密和骨架关系协调；在米字格或归一化坐标中，关键部件位置稳定，内部空腔不过挤也不过散。不同书体要分组比较，不能拿楷书模板直接评草书。

**理论/证据**：中国书法传统中的结字/结体；Chiang Yee；Shi 对 brushstrokes、characters、compositional structure 三个层次的讨论；Zhang 等开放全文对 skeleton、inner/outer contour、rice-grid area 的实现。

### C3 布白/章法 Spatial Arrangement / Negative Space

**观察规则**：字内空白、字间距、行间距、边界留白和整体密度形成有层次的空间组织；留白不是“越多越好”，而是与墨量、重心和观看路径共同作用。

**理论/证据**：书法鉴赏中的章法与布白传统；Shi 的空间/构成讨论；Zhang 等人对米字格区域占比、外内轮廓和作品布局的计算；Locher 等人的构图平衡研究可作为跨媒介方法参考。

### C4 墨法/墨色层次 Ink Tone / Ink Distribution

**观察规则**：浓淡、干湿、枯润、边缘渗化和局部对比构成层次；评价时先排除纸张、扫描曝光和压缩伪影。对于纯黑数字字体，该项可以标记为“不适用”或只评价边缘抗锯齿，不能虚构墨色差异。

**理论/证据**：书法批评中对墨色变化的长期讨论；Shi 2019 文献注释引用 Liang Qichao 关于“光”与墨色变化的说明；Wang 等人的“Sumi”分布、墨量比；Zhang 等人的灰度/图像处理流程。

### C5 气韵/行气/力势 Qi–Yun / Shi / Movement Proxy

**观察规则**：从可见形态判断方向连续性、轻重缓急、部件/笔画之间的呼应和整体行气；不要把“有气韵”当作模型标签的原始事实，而应标记为由多个低层代理变量共同预测的潜变量。

**理论/证据**：Shi 2019 将书法解释为“force-form”，强调力势贯穿笔画、字符和构成结构；Shi 2023 讨论 qi、xing、shi 与书写动作的关系；Lu 关于古代书法节奏的研究条目；Zhang 等人以连带特征和笔画厚度序列帮助公众理解连续性。

## 4. 不应纳入这 10 项“视觉审美真值”的变量

- 获奖、媒体曝光、品牌知名度、设计师姓名、机构声望：社会学/传播变量。
- 字符语义、奖项名称、历史故事、国别标签：语义和文化变量；可用于研究附加值，但要与纯视觉评分分开。
- “看起来像某位大师”：可能是熟悉度或刻板印象，不能直接当作形式质量。

## 5. 可检验的研究假设

1. D1–D5 与纯视觉审美评分存在统计关联，但最佳值呈区间或倒 U 型，而不是单调递增。
2. C1–C5 对不同书体和不同文化组的权重不同。
3. 形状归一版更适合比较结体/线质，原版更适合比较章法/平衡，灰度版更适合比较墨法。
4. 把社会标签加入模型后，预测评分的提升若主要来自标签而非视觉特征，则说明存在附加值/刻板印象路径。
