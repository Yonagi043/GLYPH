# GLYPH 四条研究线

1. 跨文化感知线：对各主流语言的母语者进行品牌字标偏好调查，同时覆盖母语文字与非母语文字，考察美观、高级感、现代感、信任感、易读性与陌生感等评价，并消除单一中文母语者视角造成的偏差。

2. 文化—历史叙事线：梳理不同文字的起源、发展历史、当代品牌传播与文化叙事，分析“英文＝国际化/高端”“日文＝极简/禅意”等刻板印象如何形成、传播并影响字标评价。

3. 跨文字系统的视觉形式线：从纯粹视觉角度量化不同文字与字标的密度、留白、几何化程度、对称性、曲直比例、笔画/线条复杂度、节奏与比例等特征，检验这些特征与审美及高级感评价的关系。

4. 汉字内部书体与字形演化线：比较小篆、隶书、楷书、行书、草书、宋体、黑体、瘦金体等汉字书体在品牌字标中的差异，研究其视觉结构，以及古典、权威、文人、锋利、现代等文化联想如何共同影响评价。

## 每条线的 AI 研究载体

### 1. 跨文化感知线：AI 辅助社会科学实验平台

研究载体：多语种问卷系统、Persona Agent、真实受试者实验。

AI 可以用于生成不同文化背景、年龄、教育程度、设计经验与跨文化接触程度的假设性受试者画像；预演问卷；发现题目歧义；比较不同问卷措辞的可能偏差；预测可能存在的交互效应；辅助设计样本分组和实验刺激。实际实验仍由真实的中国、英语、日语、韩语等母语受试者完成。

重点问题：不同母语者如何评价母语与非母语字标？“美观”“高级”“现代”“可信”“易读”“陌生”等评价是否随文字系统、可读性和文化接触程度变化？

产出：跨文化偏好数据集、问卷版本记录、受试者背景变量、跨语言比较模型。

证据边界：Persona Agent 只能用于预测试、问卷调试和假设生成，不能替代真实受试者，也不能作为社会学结论的主证据。

### 2. 文化—历史叙事线：多语种检索与叙事挖掘系统

研究载体：多语种文献库、品牌/广告语料库、网页与社交媒体语料、叙事抽取 Agent。

AI 可以大规模检索不同语言中的历史材料、字体史、设计媒体、品牌官网、广告文案和社交媒体内容；抽取与不同文字系统共同出现的描述词；识别“英文＝国际化/高端”“日文＝极简/禅意”“小篆＝古典/权威”等叙事；按时间、品类、地区和传播渠道进行聚类与趋势分析。

重点问题：这些联想从何时开始出现？在哪些品牌品类和传播渠道中最强？它们是跨文化共识，还是特定市场中的局部叙事？这些叙事能否转化为可在第一条线中检验的假设？

产出：有来源链接的叙事证据卡、文化联想词表、时间趋势、传播网络和可检验假设库。

证据边界：流量、曝光量和社媒热度只反映传播，不直接等同于审美偏好或高级感；每一条叙事结论都必须保留原始来源与语境。

### 3. 跨文字系统的视觉形式线：可解释视觉特征与审美模型平台

研究载体：字体/字标渲染系统、计算机视觉特征提取、视觉表征模型、人类评分校准模型。

第一层是可解释视觉特征：字面覆盖率、黑白密度、留白比例、笔画或线条复杂度、封闭空间数量、横纵比例、对称性、曲线与直线比例、几何化程度、重复节奏、视觉重心和轮廓复杂度。

第二层是视觉模型：使用图像 embedding、视觉表征模型或通用图像审美模型，比较受控字标之间的相似性和潜在视觉维度。模型输出只能作为辅助变量，而不是“好看”的真值。

第三层是统计解释：将真实人类对美观、高级感、现代感、易读性等评分，与视觉特征、文字系统、可读性、文化熟悉度和品牌品类共同建模，估计每类因素的独立贡献。

重点问题：在控制文字身份、品牌名称、版式和色彩后，哪些纯视觉特征仍能预测高级感？控制这些特征后，文字系统标签是否仍有剩余效应？

产出：带稳定 ID 的字标刺激库、视觉特征表、模型表征、人与模型对照结果、可解释预测模型。

证据边界：视觉模型不能被当成审美裁判；任何“模型偏好”都必须与人类评价对照，并报告模型的文化偏差和失效条件。

### 4. 汉字内部书体与字形演化线：书体知识图谱与专家在环字形系统

研究载体：汉字书体数据库、字形/笔画结构表示、书体知识图谱、控制变量生成系统、书法与篆刻专家审核。

AI 可以为不同书体建立字符级记录：字形轮廓、笔画结构、比例、重心、曲直关系、历史时期、使用场景和文化标签；也可以在控制文字内容、画布和字面面积的前提下生成候选字标，用于比较小篆、隶书、楷书、行书、草书、宋体、黑体、瘦金体等书体。

重点问题：汉字内部不同书体的审美差异是否大于“汉字与外文”的平均差异？小篆等书体的吸引力来自纵向比例、对称、线条均匀和图形性，还是来自古典、印章、权威等文化联想？不同书体分别适合什么品牌品类？

产出：汉字书体—字形—历史—文化联想知识图谱、专家校验后的刺激集、书体特征表、场景适配模型。

证据边界：书体不只是字体文件和图像风格。AI 可以分析与生成候选，但书法、篆刻或字体设计专家必须审核字形结构、书写逻辑和历史解释；真实受试者负责评价其审美和品牌适配度。

## 统一的 Agentic Workflow

四条线共享同一套刺激 ID、变量字典、来源记录和结果格式，避免形成四份互不相干的报告。

1. Evidence Agent：检索文献、历史材料、品牌传播与文化语料；形成带来源链接的证据卡和叙事假设。
2. Stimulus Agent：生成、编号和质检字标刺激；记录文字系统、书体、字体、字面面积、颜色、版式、可读性和文化语境。
3. Experiment Agent：生成多语种问卷草案、管理随机化和样本配额、检查翻译与量表等价性；组织真实受试者实验。
4. Vision Agent：提取视觉特征、运行视觉表征模型、生成特征表和质量检查报告。
5. Analysis Agent：将人类评分、文化变量、视觉特征和书体变量放入同一统计模型；报告效应、不确定性和混杂因素。
6. Audit Agent：检查来源、变量控制、数据缺失、模型偏差和结论是否超出证据；只提出问题和修正建议，不擅自修改实验条件。

统一流程：研究问题与假设库 → 多语种检索与文化叙事挖掘 → 字形/字标生成与视觉特征提取 → 真实受试者实验 → 联合统计分析 → 人工审计 → 下一轮实验。

人工关卡：研究假设必须人工确认；实验刺激必须人工确认控制变量；所有研究结论必须由人工确认没有超出数据与来源的支持范围。
